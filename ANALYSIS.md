# Subroutine analysis

Names are deliberately conservative. They are generated by `tools/enrich_asm.py`, so they survive `make disassemble`. Confidence refers to the semantic name, not merely the entry-point boundary.

## Startup and hardware

| Address | Name | Confidence | Evidence |
|---:|---|---|---|
| `0x0518` | `fill_memory` | High | Stores A at HL, copies that byte forward with LDIR. |
| `0x0521` | `init_main` | High | Reset target; resets SCC A, initializes SRAM, hardware, queues, then enters the service loop. |
| `0x0848` | `init_terminal_scc` | High | Writes register tables and baud constants through channel B control port `0xf2`. |
| `0x093d` | `init_modem_scc` | High | Resets and programs channel A through control port `0xf0`. |
| `0x098c` | `write_scc_a_register_table` | High | Writes B bytes from HL to `SCC_A_CTRL`. |
| `0x0993` | `write_scc_a_wr3_wr5` | High | Selects WR3 and WR5 and writes C/B respectively. |
| `0x09be` | `program_scc_a_baud_rate` | High | Selects WR12 and WR13 and writes a table-selected time constant. |

## Checksums and context

| Address | Name | Confidence | Interface/evidence |
|---:|---|---|---|
| `0x0a1b` | `iy_read_word_at_offset` | High | IY base + DE byte offset; returns little-endian word in HL. |
| `0x0a26` | `iy_write_word_at_offset` | High | IY base + DE byte offset; stores HL and returns destination in HL. |
| `0x0a43` | `compute_rom_checksum` | High | Sums `0x8000` bytes starting at ROM address zero and stores A at `0x8825`. |
| `0x0a50` | `compute_saved_settings_checksum` | High | Sums `0xaa04` bytes beginning at battery-backed SRAM `0x802b`. This is 4 × 0xaa bytes because the checksum primitive uses B as an inner 256-byte counter. |
| `0x0a5a` | `verify_saved_settings_checksum` | High | Compares calculated checksum against byte `0x881d`. |
| `0x0a62` | `store_saved_settings_checksum` | High | Recomputes and stores checksum at `0x881d`. |
| `0x0a69` | `additive_checksum` | High | Input HL/BC, accumulator reset to zero; loops with B then decrements C. |
| `0x112b` | `select_channel_context` | High | Maps channel A=0..9 to a fixed-size record based at `0x83a5`, returned in IY; carry indicates invalid channel. |

## Remaining work

The next useful passes are:

1. Identify every queue descriptor and assign SRAM names.
2. Decode channel A/B SCC initialization tables into WR register/value comments.
3. Name interrupt handlers and the HDLC receive/transmit state machine.
4. Map the command dispatch table around `0x1a00`-`0x2223`.
5. Map mailbox message storage and linked-list routines around `0x3c00`-`0x4e84`.

The RST entries at `0x0008` and `0x0020` are intentionally not given stronger semantic names yet; their current bytes/control flow require more context.
